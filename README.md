
# Serica Draco — Tech & Biz Consulting

A responsive, English-language website for independent China-based technical,
engineering and business consulting and representation.

## Website structure

- `index.html` — main website
- `assets/css/style.css` — styling and responsive layout
- `assets/js/script.js` — mobile navigation and copyright year
- `assets/images/serica-draco-logo.png` — business logo
- `assets/images/fabio-costa.jpg` — professional portrait

## Publishing with GitHub Pages

1. Upload or commit the website files to the root of the repository.
2. Open the repository's Settings.
3. Select Pages.
4. Configure publishing from the `main` branch and the `/ (root)` folder,
   if that matches your repository's branch and current configuration.
5. Save and wait for GitHub Pages to publish the site.

Website repository:
https://github.com/SERICADRACO/sericadraco.github.io

## Before publishing

- Confirm that the logo and portrait filenames match the paths in `index.html`.
- Review the wording, services, experience and contact details.
- Test the website on desktop and mobile.
- Check that all images load correctly.
- Check all navigation, email and LinkedIn links.
